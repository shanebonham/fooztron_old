# Changelog

## 2.0.0 (2026-11-12)

### Added
- Live scoring with per-rod goal attribution and undo
- Real-time sync across all connected clients
- 3D arena with live goal replays and a jumbotron display mode
- FoozRank positional ratings
- Live win probability
- Lineup balancing
- Player profiles with rating history, splits and head-to-head records
- 18 achievements
- Match reports with 3D replay
- Spoken commentary and stadium audio
- History page
- Prometheus metrics and health endpoint
- Docker image and CI

### Changed
- Rebuilt on TypeScript, React, Three.js and Node.js
- Data model is now event-sourced

### Preserved
- All version 1 leaderboards
- Match rules: first to 10, white vs. blue, offense and defense
- Version 1 source in `legacy/2012-rails`

## 1.0.0 (2012-07-12)

Final version 1 release.
